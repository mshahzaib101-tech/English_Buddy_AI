# English Buddy AI

> **Speak. Practice. Improve.**

English Buddy AI is an AI-powered English learning and Communication Skills practice app designed for students and English learners.

## ✨ Features

- 🗣️ AI English conversation practice
- 🎤 Voice speaking practice
- ⌨️ Text-based practice when microphone is unavailable
- ✍️ AI grammar correction
- 🔄 English → Urdu translation practice
- 🔄 Urdu → English translation practice
- 📚 Vocabulary building
- 🎯 Daily English practice
- 🎤 Presentation practice
- 💼 Interview practice
- 🤖 AI roleplay scenarios
- 📊 Learning progress tracking
- 🎓 Communication Skills practice

## 🛠️ Tech Stack

- React
- Node.js
- Firebase Authentication
- Firebase Firestore
- Google Gemini API
- Google AI Studio

## 🎯 Target Users

- University students
- English beginners
- Communication Skills students
- Interview and presentation learners

## 🚀 Project Goal

The goal of English Buddy AI is to help students improve their English speaking, grammar, vocabulary, translation, and communication skills through interactive AI-powered practice.

## 🔐 Security

API keys and sensitive credentials should never be committed to the repository. Environment variables and secure server-side configuration should be used.
